# Security

Propane-Privacy is a research build. It has not been audited, it is not deployed, and there is no bug bounty.

## Reporting

Please report a vulnerability privately by email to adiiiresearch@gmail.com or biradaraditya9712@gmail.com rather than in a public issue. Include the affected contract, the steps to reproduce (a Foundry test is ideal), and the impact you expect.

## Scope

The contracts under `contracts/src/`, including any way to learn encrypted balances, attributes or counters from what the contracts disclose. Issues in Zama's fhEVM itself belong with Zama; report them here only if the bug is in how Propane uses it.
